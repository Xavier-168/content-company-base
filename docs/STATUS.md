## 目前有意保留的边界

- 首版单用户、单发布账号任务；一个 state 首次核验固定本人，不提供多用户权限或 OS 执行沙箱。换人需要独立配置 / state 与本人自己的供应商授权，保留原数据。
- 运行要求 Python 3.11+；平台限定 macOS / Linux，Windows 待补。Linux 官方镜像结果与 macOS 测试分别记录，不把 Node / 进程夹具跳过项记成全测。
- 没有内置模型、自动采集、定时无人发布、自动建表或批量改旧记录。
- 同一 state 内有按 Base / table / record 的跨进程资源锁，活进程不被恢复为 unknown；飞书写入仍是本地乐观快照门禁，不是远端原子 CAS。其他客户端的并发写入不受本机锁保护。
- `verify-write` 只证明当前目标字段匹配，不证明原请求回执；私有 receipt.json 恢复只帮助查询原任务，不重发。
- 供应商 CLI 的授权、版本、账户与服务费用由使用者准备，项目不附带凭据。
- Web 单素材 20 MiB，较大视频通过 CLI；未知任务保留，不自动重发。
